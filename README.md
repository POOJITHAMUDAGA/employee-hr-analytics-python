# Employee HR Analytics

## Project Overview

Employee HR Analytics is a Python-based data analysis project designed to analyze employee information and identify useful insights related to salary, experience, department, and designation.

The project uses Python to process employee data, perform statistical analysis, and visualize important HR metrics using charts.

## Objectives

- Analyze employee salary information.
- Calculate average salary by department.
- Analyze salary based on years of experience.
- Identify employees with 5 or more years of experience.
- Analyze salary ranges.
- Compare individual employee salaries.
- Analyze salary based on designation.
- Analyze average salary by department.
- Identify the highest and lowest-paid employees in each department.

## Technologies Used

- Python
- Matplotlib
- Basic Python data structures
- Data analysis techniques

## Key Analysis Performed

### 1. Experience Analysis
Calculated the average years of experience and identified employees with 5+ years of experience.

### 2. Experience-Wise Salary Analysis
Compared average salary across different experience levels.

### 3. Salary Range Analysis
Grouped employees into different salary ranges to understand salary distribution.

### 4. Designation-Wise Salary Analysis
Compared salaries across different job designations.

### 5. Department-Wise Salary Analysis
Calculated and compared average salaries across Finance, Marketing, IT, and HR departments.

### 6. Highest and Lowest Salary Analysis
Identified the highest-paid and lowest-paid employees within each department.

### 7. Data Visualization
Created bar charts using Matplotlib to visually compare employee salaries and department-level average salaries.
